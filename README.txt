НА ГЛАВНЫЙ ЭКРАН
На общей странице и в каждом тренажёре есть кнопка «На главный экран».
Браузер с поддержкой установки покажет системное подтверждение; остальные
получат инструкцию по созданию ярлыка. Отдельное окно зависит от браузера.
Huawei Browser: меню → В закладки → Рабочий экран → галочка.
Яндекс на Android-планшете: меню → Добавить на домашний экран → Добавить.
Официальные инструкции:
https://consumer.huawei.com/ru/support/content/ru-ru00706885/
https://yandex.ru/support/browser-mobile-android-tablet/ru/troubleshooting/problems-site

PWA И РЕСУРСЫ
Корневая и три вложенные страницы имеют отдельные manifest.webmanifest
с уникальными id, названиями, PNG-иконками и режимом standalone.
Общий pwa.js регистрирует sw.js в области текущего каталога проекта.
Рабочие страницы не перезагружаются принудительно. Первый запуск требует
интернета. Рабочие файлы письменных заданий сохраняются в небольшом кеше;
MP3 автоматически не скачиваются, для озвучки нужен интернет.
При изменении рабочих файлов следует обновить VERSION и CORE в sw.js.
Кеш отделён от других сайтов на том же домене. localStorage не очищается.

ПРОГРЕСС
Старые сайты и их прогресс не удалены. Этот адрес использует отдельное
хранилище браузера. У трёх тренажёров разные ключи прогресса.
Установка значка сама по себе не переносит данные между браузерами.

ПУБЛИКАЦИЯ
GitHub Pages: main, /(root), HTTPS. .nojekyll сохраняет готовые статические
файлы без Jekyll. Серверный код, API-ключи и внешние шрифты не нужны.
Аудиофайлы, источники и лицензии хранятся внутри каждой папки тренажёра.
Проверки Node VM не заменяют проверку установки на конкретном устройстве.
