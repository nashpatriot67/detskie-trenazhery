НАШИ ТРЕНАЖЁРЫ — ПЕРЕНОСИМАЯ КОПИЯ

Внутри три текущих тренажёра с заданиями, объяснениями и готовыми
записями женского голоса. Вход ребёнку и аккаунты посетителей не нужны.

РАЗМЕЩЕНИЕ
Разместите всё содержимое этой папки на статическом HTTPS-хостинге.
Главная страница — index.html. Подпапки kubiki, bricks, slovograd и
audio внутри каждой из них должны сохранить свои имена и структуру.
Серверный код, база данных, API-ключи и внешние шрифты не требуются.
Из общей страницы ссылки ведут к трём тренажёрам на том же хостинге.
Скачанный из приложения HTML использует аудио с текущего адреса
размещения, а не со старого домена chatgpt.site.

ЛОКАЛЬНАЯ ПРОБА
Полностью распакуйте архив. Откройте otkryt-bez-interneta.html в браузере.
Он ведёт к offline.html внутри каждого тренажёра: в этих страницах CSS
и JavaScript встроены, а аудиофайлы находятся рядом в audio/voice1.
Не открывайте HTML прямо внутри ZIP. Доступ к относительным файлам
зависит от браузера и файлового менеджера устройства. Локальная запись
и голосовой ввод могут требовать HTTPS и разрешения браузера.

ПРОГРЕСС
Старые сайты и их прогресс не удаляются. Другой адрес сайта или локальный
файл используют отдельное хранилище браузера: прежний прогресс туда
автоматически не переносится. У трёх тренажёров разные ключи прогресса.

ПРОВЕРКА ДОСТУПА
Этот пакет готов для размещения, но новый адрес ещё не выбран.
Доступ без VPN необходимо проверить из нужной страны и сети на самом
планшете. Архив не доказывает доступность будущего хостинга.

ОЗВУЧКА
Все MP3 включены. Источники и лицензии находятся в voice-credits.txt
и voice-license.txt внутри каждой папки тренажёра. Для произвольного
текста ребёнка Словоград отдельно использует голос устройства.
